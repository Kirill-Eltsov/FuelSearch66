# FuelSearch66 — инструкция для проверки

Учебный проект: карта АЗС Свердловской области, фильтр по топливу, отметки и избранное (localStorage).

Репозиторий: https://github.com/Kirill-Eltsov/FuelSearch66

---

## Что нужно на компьютере

- Git
- Node.js **18+** (лучше LTS) и npm  
  Проверка в терминале: `node -v` и `npm -v`

---

## 1. Клонировать репозиторий

```bash
git clone https://github.com/Kirill-Eltsov/FuelSearch66.git
cd FuelSearch66
```

---

## 2. Установить зависимости

В корне проекта (где лежит `package.json`):

```bash
npm install
```

---

## 3. Запустить у себя локально

```bash
npm run dev
```

В терминале появится адрес, обычно:

`http://localhost:5173`

Открыть его в браузере (Chrome / Edge / Firefox).

Остановка сервера: `Ctrl + C` в терминале.

---

## 4. Сборка (по желанию)

```bash
npm run build
npm run preview
```

---

## Что проверить в интерфейсе

1. На главной загружаются АЗС (карта Leaflet + список). Если Overpass временно недоступен — будет ошибка и кнопка «Повторить».
2. Фильтры АИ-92 / АИ-95 / АИ-100 / ДТ (показывают станции с локальной отметкой «есть» по выбранной марке).
3. Открыть карточку АЗС → сохранить отметку → обновить страницу (данные остаются).
4. «В избранное» → раздел **Избранное**.
5. Страница **О проекте**.

Чеклист: `docs/MVP_CHECKLIST.md`.

---

## Возможные проблемы

| Проблема | Что сделать |
|----------|-------------|
| `git` / `node` / `npm` не найдены | Установить Git и Node.js LTS |
| Ошибка при `npm install` | Удалить `node_modules` и `package-lock.json`, снова выполнить `npm install` |
| Долго грузятся АЗС / ошибка Overpass | Подождать и нажать «Повторить»; нужен доступ в интернет |
| Порт 5173 занят | Vite предложит другой порт — открыть адрес из терминала |
