# FuelSearch66

Клиентское веб-приложение для поиска АЗС и отметок о наличии топлива в Свердловской области.

## Идея

Пользователь (водитель) открывает карту/список АЗС, фильтрует по марке топлива (АИ-92 / АИ-95 / АИ-100 / ДТ), открывает карточку станции, оставляет локальную отметку о наличии и сохраняет АЗС в избранное.

## MVP (из Mini PRD)

- Карта и список АЗС (данные OpenStreetMap / Overpass)
- Фильтр по марке топлива
- Карточка АЗС
- Отметки есть / нет / мало / очередь (localStorage)
- Избранное (localStorage)

Не входит: регистрация, серверная синхронизация, оплата, навигация маршрута.

## Стек

- React + Vite
- Leaflet + OpenStreetMap
- Overpass API
- localStorage
